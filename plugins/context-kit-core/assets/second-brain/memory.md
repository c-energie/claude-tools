## What this is

The cross-project context layer — the level above the per-project context repos. Sessions here
load this repo **plus** the context of every project named in `context.json`'s `include` list.
Its two jobs, in order: **cross-pollination** — a place where an insight from one project can
inform another — and a **personal layer** for facts and commitments that no single project owns.

It is deliberately *not* a task-triage dashboard and not a substitute for working in a
project's own session.
